# One In Him app review — 17 October 2026

Reviewed the published learner prototype in the browser, with seven captured steps, then checked the implementation. Release 228 preserves the orange/black branding, source artwork, content, and existing Supabase permissions. No paid services were enabled.

## Flow review

1. **Discover — improved.** Published documentary cover art was overwritten by a generic resource fallback. Preserve the editor's selected artwork. Add a direct Journey navigation action. Pause hero rotation while someone interacts with it and respect reduced motion.
2. **Watch — improved.** The same fallback caused different videos to appear identical. Restore distinct covers and keep Watch selected when opening its detail page.
3. **Teaching detail and lesson handoff — fixed.** A transparent fixed header intercepted the top-right lesson button. Stop the transparent area capturing clicks, shorten the header on content screens, and give the detail page a consistent dark surface. Replace the Share-to-home action with sharing/copying and restore shared resource links on load. Add a visible return action.
4. **Account — improved.** Ordinary learners reached an admin-only login. Show local learner progress and a journey action first, with team sign-in inside a disclosure. State that progress/notes are device-local and that clearing browser data removes them. Do not imply cloud profiles exist.
5. **Partner library — clarified.** Partner sign-in incorrectly led to the admin form. Replace that dead end with a free-journey return and a note that partner sign-in is unavailable in this prototype. Existing prototype access behavior is preserved; it is not a production membership system.
6. **Feed — clarified.** Sample posts and local reflections looked like public community activity. Label the preview, explain local storage, rename the action Save thought, remove invented likes on the learner's own entries, make text sharing work, and handle storage failures. Notifications no longer suggest unread activity.
7. **Journey and lessons — fixed.** Fresh users saw hard-coded completion percentages, and completed lessons were lost on reload. Start at zero, derive section progress from actual completed steps, and persist completion/practice/review sets in local storage. Retain browser Back/Forward navigation.

## Additional fixes

- Replace the older embedded root index with a redirect to the canonical app, preserving deep links.
- Start installed apps directly at the learner app rather than resetting the cache on every launch.
- Add offline fallback for cached app shell files and scope service worker cleanup to this app.
- Add selected-navigation semantics, visible keyboard focus, a skip link, announced status messages, longer readable toast timing, mobile wrapping and input sizing, and clearer learner/admin separation.

## Validation and limits

Automated DOM regressions cover navigation into a real lesson, zero initial progress, persistence across reloads, actual progress calculations, cancelled sharing without rewards, shared-resource deep links, history restoration without extra entries, language switching, cover artwork, and local-feed disclosure. Run `npm ci && npm test`.

The browser review covered desktop layouts. Phone breakpoint changes were reviewed in source; this environment did not provide a phone-sized browser viewport. No claim of full accessibility compliance is made. Native share sheets, real admin authentication, member entitlements, cross-device sync, and every media item require additional integration/device testing. The feed and membership behavior remain prototype features.
