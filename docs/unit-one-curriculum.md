# Unit 1: Knowing God through Jesus

Unit 1 contains five content modules. Questions, reflection and practice are separate and do not increase the content percentage.

| Module | Format | Supplied source |
| --- | --- | --- |
| Eternal Life · Part 1 | Video, 6 min | One Basics 1.1, existing 00:00–06:00 segment |
| More than living forever | Written, 2 min | One Basics 1.1 study guide, teaching paragraphs 1–2 |
| Eternal Life · Part 2 | Audio, 6 min | Audio from the original One Basics 1.1 teaching, existing 06:00–12:00 segment |
| Knowing the Father through Jesus | Written, 4 min | One Basics 1.1 study guide, teaching paragraphs 3–6 |
| Eternal Life · Part 3 | Video, 6 min | One Basics 1.1, existing 12:00–18:00 segment |

The written material is taken from `pkg_one_basics_1_1_eternal_life`, already supplied in the app. The source's final questions paragraph is excluded from the written modules. Media uses the existing verified One Basics 1.1 playback source, with the clip boundaries already recorded in the published packages. Audio is the original teaching's soundtrack, displayed using Mux's documented audio UI; no generated narration or unrelated podcast is substituted. These segments do not claim to contain the entire 27-minute episode or a new transcript.

The ring and visible percentage advance 0 → 20 → 40 → 60 → 80 → 100 as the five content modules are completed. Continue records the current content module before its separate questions. Skip does not complete it. Practice/review completions never inflate the ring. Resume opens the first unfinished module. An older first-video completion is retained as one module (20%); new modules use stable resource IDs so numeric positions do not falsely complete added content.

Existing future units are retained. Signup, email delivery and database permissions are unchanged.
