# Five-module journey curriculum

Every unit has five content modules. Questions, review and practical choices do not add to the completion ring. Each completed module adds 20%.

Existing supplied teachings are retained in order. A final group with fewer than five lessons is filled by splitting its longer written sources into consecutive, nonoverlapping parts. No question page, duplicate content, unrelated media or placeholder is used as an extra module. Explore Jesus units 2 and 3 use the supplied Saved by Grace and Intimacy with God study guides. Only verified media is labelled video/audio; other supplied lessons remain written.

Old numeric lesson completions and notes are read using their v231 source mappings. New completions and notes use stable resource IDs. Regrouped unit practice/review badges use the unit's content identity, so an old badge cannot complete an unrelated unit.

## Question feedback

The old Check handler never compared the selected option with the correct answer before showing success. Now each knowledge check has one correct option: incorrect choices show “Not quite” and “Try again”, keep the current module open, and never mark a review complete. Correct choices show an explanation and Continue. The five opening modules have distinct checks grounded in the supplied Eternal Life study guide and its cited verses. Practical actions are explicitly ungraded choices and show a neutral acknowledgement. Questions remain separate from content completion.

Validation: every answer option across all 90 modules, 18 five-module unit counts, every source retained, split-source coverage, all 20% increments, wrong review attempts, practical choices, resume/reload and legacy notes/completions.
